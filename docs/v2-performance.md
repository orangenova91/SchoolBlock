측정 스크립트와 원본 결과는 `scripts/v2-perf/`에 있다.

- 상세 표: `scripts/v2-perf/results/2026-10-15/report.md`

## 1. 측정 방법

- **데이터**: DB 없이 메모리에서 학교를 만든다 (`scripts/v2-perf/school.ts`, 시드 고정).
  - 2022 개정 교육과정 일반고 편제를 단순화: 주당 32시간, 1학년 공통과목,
    2·3학년 학교 지정 과목 + 선택 묶음(SET). 기본 SET 비중 2학년 38%, 3학년 63%.
  - 참고 편제: 2026학년도 입학생 – 통합사회·통합과학 각 8학점, 과학탐구실험 2학점,
    2학년 지정 11학점·선택 18학점/학기, 3학년 개별 선택 27학점
    ([지역내일 2026.10.07](https://www.localnaeil.com/News/View/654886)).
  - 교사 시수 1인 10~22시간, 같은 학교 안 최대/최소 2배 이내.
- **경로**: 화면과 같다. 사전 검사(빠른 검사 + 정확 판정) → 배치 가능하면 v2 생성
  (최대 30초, 기본 가중치 3/2/3) 3회. 6개 시나리오 동시 실행.
- **시나리오**: 기준에서 한 축만 바꾼 변형(규모·교사 수·제약·SET) + 현실 조합 4개 + 극단 조합 3개.
- v1은 측정하지 않았다.

## 4. 해석

- **안정성**: 배치 가능/불가 판정과 "가능하면 미배치 0"이 모든 조건에서 지켜졌고,
  판정 1.5초·생성 30초 이내로 끝났다.
- **품질 요인**: 교사 부하, SET 비중, 배정 불가·선 수업 비율이 클수록 점심 연강이 는다.
  학교 규모는 품질에 큰 영향이 없었다.
- **반복 간 차이 작음**: 같은 시나리오의 3회 결과가 대부분 같다. 정확 판정이 매번 같은
  초기 배치를 주기 때문으로 보인다(안정적이지만 탐색 폭은 좁음).

## 5. 한계와 다음 단계

- 생성 데이터는 교과별 교사 배정이 고르게 퍼져 있어 실제 학교보다 조건이 덜 부딪힐 수 있다.
  기준 시나리오의 점심 연강은 1이었지만, 실제 데모 데이터(SET이 3학년 1~3교시에 몰림)는 약 25였다.
  실제 학교 데이터로의 측정이 필요하다.
- SET 과목을 여러 교사가 번갈아 맡는 순환 배정은 생성기에서 다루지 않았다.
- 실제 평균 시수가 목표보다 낮게 나오는 생성 규칙은 필요하면 보정한다.
- 측정 환경: Windows, Node 24, 6개 동시 실행. 교환 개선은 시간 기준이라 환경에 따라 품질이 조금 달라질 수 있다.
