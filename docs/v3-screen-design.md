# v3 7단계: 화면 설계 (2026-10-17)

화면 목업: [SchoolBlock v3 화면 설계](https://claude.ai/artifact/XrwctadK25mHE4JA8EfsNg). 비공개 링크라 공유 메뉴에서 공유해야 다른 사람이 볼 수 있다.

기존 화면 스타일을 따랐다. 흰 카드, 회색(zinc) 글자, 검정 기본 버튼, 정보 파랑·주의 노랑·오류 빨강·완료 초록 상자를 쓴다.

## 화면 목록

| 번호 | 화면 | 핵심 |
|---|---|---|
| ① | 홈 | "새 시간표 작성(v3)" 버튼. v3 학기에 v3 표시, 진행 중인 작업 표시. 누르면 `/v3/terms/…` |
| ② | SET 고정 배치 | 칠한 회차 = 고정, 비움 = 자동. SET별 "고정 n / 회차 수". 같은 SET 요일 배분 규칙 안내. **자동 배치 버튼 없음**. 순환 교사(지정 = 유지, 비움 = 자동). 고정의 영향 계산. 빠른 검사 결과 |
| ③ | 추가 조건 | 점심 연강·3연강·동일 교과 (켜기/끄기 + 중요도 1·2·3·5·10). 항상 지키는 규칙. 목표 달성 기준 설명(예시 포함) |
| ④ | 시간표 생성 · 진행 중 | 빠른 검사(통과/주의). 방식 버튼 3개(탐색·정수계획·혼합). 진행 패널: 작업 번호·상태·구간·시간 막대, 현재 최선·이론상 최선·근접 기준·모은 결과 수, 중지, 사전 승인 토글. 작업 목록(실행 1 + 대기) |
| ⑤ | 이어 돌리기 승인 | 상태 4가지: 승인 대기 / 승인 후 대기열 / 30분 완료 / 입력이 바뀌어 이어 갈 수 없음 |
| ⑥ | 결과 3개 비교 | 순위별 점수·항목별 수치·달성 여부·1위와 다른 칸 수. 선택한 결과의 시간표 보기(기존 보기 4종). 고정 SET(진한 테두리)과 자동 배치 SET(점선) 구분. 적용 = 확정 버전 저장 |
| ⑦ | 배치 불가 원인 안내 | 경우 3가지: 빠른 검사 확정(원인 교사·부족 칸) / 정확 판정 증명 + "이 조건 하나만 풀면 가능" / 판정 미완. 요청 시 진단(데이터 한계, 고정의 영향) |

## 화면에 반영한 확정 정책

- 사용자 배치 SET = 고정, 나머지 자동 (요구사항 8.1)
- 같은 SET 하루 1회, 남을 때만 층층이 추가 (H12)
- 근접 기준: 10%와 6점 중 너그러운 쪽. 달성 여부와 관계없이 결과와 점수·기준 표시 (8.2)
- 방식별 버튼 (8.3)
- 5분 구간, 사전 승인, 중지, 30분 최대, 이어 돌리기 5분 단위, 중단점 30일 (8.4, 5단계)
- 결과 최대 3개, 서로 30칸·5% 이상 차이 (8.5)
- 진단: 빠른 검사 항상, 고정 손실·데이터 한계는 요청 시 (4단계)
- 입력 화면 공유, v3 SET 화면에 자동 배치 버튼 없음 (6단계)

## 확정 사항 (2026-10-17, 기본값 적용)

1. 주소로 v1 화면(`/terms/…`)에서 v3 학기를 열면 v3 화면으로 자동 이동한다. v1 레이아웃에 이동 한 줄만 넣고, 생성 로직은 건드리지 않는다.
2. 방식 버튼 중 혼합에 "추천"을 표시한다.
3. 결과를 적용할 때 확정 버전 메모를 자동 기록한다 (예: "v3 · 혼합 · 27점 (최선 24, 달성)").
