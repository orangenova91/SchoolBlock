# v3 실험: SET을 먼저 배치하는 것이 유리한가 (2026-10-15)

v3 운용 방침은 다음과 같다. 사용자가 직접 배치한 SET은 고정하고, 배치하지 않은 SET은 생성 단계에서 자동으로 배치한다.
이 실험에서는 최종 단계의 처리 순서가 결과 품질과 소요 시간에 주는 영향을 비교했다.

## 1. 실험 방법

- 데이터: 체험용 시간표(실제 학교 기반, 교사 39명, SET 11개, 순환 과목 포함). 동일 교과 금지는 전부 적용했다.
- 조건 4가지
  - 제약 없음 / 배정 불가 5% + 선 수업 5%
  - 각각에 대해 사용자 고정 SET 없음 / 절반 고정(원래 학교 위치)
- 방식
  - **A. SET 먼저 고정**: 나머지 SET을 감점 기반으로 먼저 배치해 고정한 뒤, 공통 수업만 탐색한다(v2 방식).
  - **B. SET 먼저 + 함께 탐색**: A의 SET 배치를 시작점으로 두고, SET 회차 이동까지 함께 탐색한다.
  - **C. 순서 없음**: SET을 규칙만 지킨 무작위 위치에 두고 시작해, 함께 탐색한다.
  - **기준값(정수계획법)**
    - SET 자유 최적: 고정되지 않은 SET 위치와 순환 교사까지 변수로 둔다.
    - A의 SET 배치에서 공통 수업만 최적화(= SET 먼저 고정 방식의 한계)
- 탐색 시간 30초 / 120초, 각 3회 반복. 점수 = 점심 연강×3 + 3연강×2 + 동일 교과×3 (낮을수록 좋음)
- 결과 시간표는 별도 검증기로 반 겹침, 교사 겹침, 배정 불가, SET 회차 수, 시수, 선 수업 유지를 확인했다.

## 2. 결과 (점수, 3회 평균 / 최고) — 2026-10-16 재측정

> **정정**: 첫 측정의 탐색 프로토타입에는 교사 겹침을 놓치는 결함이 있었다. 한 교사가 같은 SET 회차에서 두 과목을 맡는 경우(2학년 C SET)를 보지 못했다.
> 결함을 고치고(과목별 담당 교사 관리, 순환 교사 맞바꾸기 추가), 검증기에 같은 회차 안 겹침과 순환 시수 검사를 넣어 다시 측정했다.
> 정수계획법 기준값(이론상 최선)은 과목별로 세므로 영향이 없다. 결론은 바뀌지 않았다.

| 조건 | 최적(SET 자유) | SET 먼저 고정의 한계 | A 120초 | B 120초 | C 120초 |
|---|---|---|---|---|---|
| 제약 없음 · 고정 없음 | **24** | 66* | 배치 불가 | 26.3 / 24 | 30.0 / 26 |
| 제약 없음 · 절반 고정 | **27** | 95* | 배치 불가 | 38.7 / 29 | 40.3 / 34 |
| 불가 5%·선 5% · 고정 없음 | **24** | 78* | 배치 불가 | 43.7 / 36 | 55.0 / 55 (3회 중 2회 미배치) |
| 불가 5%·선 5% · 절반 고정 | **52** | 80* | 배치 불가 | 79.0 / 77 | 76.0 / 76 (3회 중 2회 미배치) |

- **A(SET 먼저 고정)는 모든 실행에서 미배치 3이 남아 시간표를 만들지 못했다.**
  SET 위치를 정한 뒤 앱 추천대로 순환 교사를 정하면, 2학년 C SET에서 같은 교사가 같은 시간에 두 과목에 배정된다.
  SET을 고정하면 이 겹침을 풀 방법이 없다.
- \* "한계" 값은 이 겹침을 무시하고 계산한 값이다. 겹침이 없더라도 SET 자유 최적보다 2.5~4배 나쁘다.
- 30초 결과도 경향이 같았다. B는 120초에서 30초보다 5~15점 좋아졌다.
- 정수계획법으로 최적을 증명하는 데는 SET 자유 조건에서 3.5~12.5분이 걸렸다.

## 3. 결론

1. **SET을 먼저 고정하는 순서는 최종 로직으로 쓰면 안 된다.**
   공통 수업을 완벽하게 배치해도 SET 자유 최적보다 1.5~4배 나쁘다(66 대 24, 95 대 27).
   SET 위치가 정해지는 순간 품질의 상한이 정해지기 때문이다.
2. **SET을 먼저 놓는 것은 시작점으로만 쓴다.**
   제약이 없으면 규칙을 지킨 시작(B)과 무작위 시작(C)의 품질은 비슷했다.
   제약이 있으면 무작위 시작은 최종 결과에도 미배치가 남았다(6회 중 4회).
   미배치 0이 필수이므로, 교사·배정 불가·선 수업을 지키는 SET 시작 배치가 필요하다.
3. **권장 순서**: ① 사용자 고정 SET 반영 → ② 남은 SET을 규칙을 지키며 빠르게 배치(시작점) → ③ 공통 수업과 SET 회차 이동을 **함께** 탐색 → ④ 이론상 최선(하한)과 비교해 안내
4. **현재 탐색의 한계**: 제약이 있는 조건에서는 최적과 차이가 컸다(52 대 77, 24 대 36). 3단계에서 정수계획법 결합으로 줄이는 방법을 비교했다.
   이 차이를 줄이는 방법(정수계획법 결합, 부분 재최적화 등)은 3단계 알고리즘 비교에서 다룬다.

## 4. 실험 중 발견한 사항

- **선 수업이 많으면 SET을 놓을 자리가 거의 없다.**
  학년 전체 SET은 그 학년 모든 반이 비어 있는 시간에만 놓을 수 있다.
  선 수업 20% 조건(테스트 시간표 4의 기준)에서는 원래 SET 시간 말고는 빈 시간이 거의 없어, SET 회차 일부를 놓지 못했다.
  사용자가 선 수업을 많이 넣으면 SET 자동 배치의 여지가 사라진다는 뜻이므로, 입력 단계 경고 대상이다.
  (이 조건의 실험 결과는 무효로 처리하고, 선 수업 5%로 다시 실험했다.)
- **실험 모델 오류 수정**: 정수계획법 실험 모델(작업 폴더, 앱 코드 아님)에 오류가 있었다.
  자유 SET이 고정 SET이나 선 수업이 있는 반 칸에 놓일 수 있었다. 이를 고쳐 다시 계산했다.
  테스트 시간표 4의 m17(고정·선 수업 없음)은 이 오류의 영향을 받지 않는다.

## 5. 한계

- 학교 1곳의 데이터이고, 배정 불가·선 수업은 원래 SET 위치를 피해 무작위로 만들었다.
- 탐색은 프로토타입이다. SET 회차를 학년 세로줄 맞바꾸기로만 옮기고, 순환 교사는 시작 배치 때 정한 것을 유지한다.
  정수계획법은 순환 교사도 회차별로 다시 정한다.
